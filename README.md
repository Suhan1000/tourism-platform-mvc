# Tourism Platform 🌏

A web-based tourism platform where you can book tours as users - manage tour as agent and use as tourguide which is built using the MVC 
(Model-View-Controller) architectural pattern.

## 🏗️ Architecture
Built using the MVC pattern demonstrating clean separation 
of concerns:
- **Model** — data and business logic
- **View** — user interface and presentation
- **Controller** — handles input and coordinates model/view

## 🛠️ Tech Stack
- ASP.NET MVC
- C#
- Visual Studio 2022
- SQL Server

## 🎯 Project Purpose
Academic project demonstrating MVC architecture principles 
applied to a real-world tourism use case.
